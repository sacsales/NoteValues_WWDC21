# NoteValues_WWDC21
Super old code for my winning WWDC21 submission: Note Values, a music theory educational game.
I was learning to play the drums over COVID, I could play a beat and basic songs, but I struggled with grasping the concept of note values. Drawing out blocks and tiles like the ones seen here helped me understand how it worked, so I decided to make a digital version.
I built this super early on in my coding journey (I was 12!) so it is **incredibly** janky and inefficient, but it had a lot of heart.  
Users can click on tiles of differing note values to hear what they sound like in one bar.
Perhaps I'll build a better version soon. 

Built using Apple's UIKit and AVFoundation. All sounds were recorded from my own drum kit. 


# Usage
- Download repo and open in Swift Playgrounds, in a landscape orientation. Make sure your volume is turned up!
